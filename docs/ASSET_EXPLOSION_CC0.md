# Proveniência do som de explosão da granada — Kenney CC0

**Conteúdo:** gravação `explosionCrunch_000.ogg`, renomeada para `assets/audio/explosions/grenade.ogg` nas builds do Frontline Survival.

**Criador original:** [Kenney — Sci-Fi Sounds](https://kenney.nl/assets/sci-fi-sounds), licença **Creative Commons Zero (CC0-1.0)**. O som é uma gravação/efeito de biblioteca, **não um beep procedural** criado pelo motor. A categoria original é ficção científica; foi selecionado um impacto grave, com edição posterior de volume via bus SFX.

**Espelho com arquivo identificado:** [GeorgeQLe/assets-sfx-combat](https://github.com/GeorgeQLe/assets-sfx-combat), em `assets/kenney/sci-fi-sounds/Audio/explosionCrunch_000.ogg`. Esse espelho registra a licença do pacote Kenney.

**Integridade Git (conteúdo original):** blob Git SHA-1 `019e53664abf859fc5529f95d0db23fa3ac1e42d`. O workflow compara `git hash-object assets/audio/explosions/grenade.ogg` com esse identificador antes de importar o Godot. Se houver alteração, o build falha em vez de distribuir um arquivo inesperado.

**Reprodutibilidade:** o CI transfere a gravação diretamente do espelho quando ainda não existe no projeto e a inclui no empacotamento Windows; depois adiciona o arquivo ao repositório no passo de sincronização de assets. O código do jogo não realiza downloads em execução.

A gravação continua CC0 mesmo após a cópia para nosso repositório. A licença permite uso comercial; mantemos o crédito voluntariamente para documentação e auditoria.

**O que não foi copiado:** nenhum áudio de Call of Duty ou outro jogo comercial.
